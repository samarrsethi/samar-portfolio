# The Samar Journal — Samar Sethi Portfolio

A cinematic, editorial-themed personal developer portfolio built with **React**, **Tailwind CSS**, **GSAP ScrollTrigger**, and **Lenis**.

---

## 📂 Project Location

- **Desktop Folder:** `~/Desktop/samar-portfolio`
- **Desktop Zip Archive:** `~/Desktop/samar-portfolio.zip`

---

## 🚀 Quick Start

### 1. Open in VS Code or Terminal
```bash
cd ~/Desktop/samar-portfolio
```
Or open the `samar-portfolio` folder directly in VS Code / Antigravity IDE / Cursor.

### 2. Start the Local Development Server
Dependencies (`node_modules`) are already installed. Simply run:
```bash
npm run dev
```
Open **http://localhost:5173/** in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production output will be generated in the `dist/` directory.

---

## 🛠️ Stack & Technologies

- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS (Custom Warm Ivory `#F5F1E8` Editorial Theme)
- **Typography:** Instrument Serif, Newsreader, Inter, JetBrains Mono
- **Animations:** GSAP 3 + ScrollTrigger, Framer Motion
- **Smooth Scroll:** Lenis
- **Icons:** Lucide React
